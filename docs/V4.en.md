# V4 Adaptive Learning & Mastery Profile

V4 adds a data-derived mastery layer on top of V3 system-graded exams, mistake review, coding labs, and automatic scoring. Users cannot manually set knowledge mastery.

## Evidence Sources

The model uses two sources:

1. per-question system-graded exam results from `exam_answers` + `exam_attempt_questions`;
2. coding-lab results from `code_attempts`.

Coding labs are stronger implementation evidence, so they receive a `1.25` source weight relative to normal exam questions.

## Mastery Calculation

For each knowledge point, the engine uses at most the 10 most recent evidence items. Newer evidence receives more weight:

```text
Newest       1.00
2nd newest   0.92
3rd newest   0.84
...
Minimum      0.35
```

Each evidence item contributes its actual score percentage. Confidence grows with repeated evidence:

```text
confidence = min(1, evidence_count / 5)
```

This prevents a single perfect answer from being treated as equally reliable as repeated strong performance.

## Mastery Levels

| Score | State | Meaning |
|---|---|---|
| no evidence | unseen | not yet assessed |
| 0–39 | weak | priority remediation needed |
| 40–69 | developing | still unstable |
| 70–84 | proficient | generally solid |
| 85–100 | mastered | mastered |

## Six-Domain Radar

The 18-week roadmap is aggregated into six capability domains:

1. Weeks 0–4: Foundations;
2. Weeks 5–7: LLM Apps;
3. Weeks 8–10: RAG;
4. Weeks 11–13: Agents;
5. Weeks 14–16: Platform;
6. Weeks 17–18: Advanced Engineering.

Domain scores are confidence-weighted aggregates of assessed knowledge points in each domain.

## Adaptive Recommendations

The system prioritizes `weak` and `developing` knowledge points using:

- mastery score;
- evidence confidence;
- historical low-score count;
- current progress in related lessons.

Each recommendation links directly to the relevant course and can generate a knowledge-specific review exam.

## Adaptive Review Exam

From `/adaptive`, choosing “Generate review exam” performs:

```text
Mastery profile
  ↓
Find weak / developing knowledge
  ↓
Collect related question-bank items
  ↓
Balance Easy / Medium / Hard questions
  ↓
Create a new timed Attempt
  ↓
Autosave + countdown + system grading
```

When no clear weak knowledge is available, the system falls back to unresolved mistakes.

## Assessment Trend

V4 combines recent system-graded exam and coding-lab scores into a single recent-performance trend. This trend is for visualization; knowledge mastery itself is still calculated from per-question evidence.

## Routes

- `/adaptive`: mastery profile, recommendations, six-domain radar, knowledge mastery, and recent assessment trend;
- `/adaptive/review/start`: generate a general weakness review;
- `/adaptive/review/start` with `knowledge`: generate a knowledge-specific review.

V4 does not add a manually maintained mastery table, so existing SQLite learning data remains directly usable.
