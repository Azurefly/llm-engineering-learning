# 超级管理员、用户管理与学习报表

多用户版本提供 `superadmin` 与普通 `user` 两种账号角色。超级管理员负责账号治理，并可以查看**学习进度、系统考试与代码实训的统计数据**；个人思考笔记、外部链接正文、代码源文件等私人学习内容仍不会进入管理员报表。

## 超级管理员产生规则

- 全新安装：第一个成功注册的账号自动成为 `superadmin`。
- 已有多用户数据升级：如果账号库中还没有超级管理员，系统自动把最早注册的现有账号升级为 `superadmin`。
- 后续超级管理员可以在“用户管理”中把其他用户提升为 `superadmin`。
- 系统始终要求至少保留一个启用状态的超级管理员；超级管理员不能在管理页停用或降低自己的角色。

## 管理入口

超级管理员登录后可以使用：

```text
/admin/users                 用户管理
/admin/report                学习运营大屏
/admin/report/data           学习报表 JSON
/admin/users/<id>/progress   单用户 Week 0～18 进度详情
```

普通用户访问这些管理员页面返回 `403`。

## 用户管理

超级管理员可以：

- 查看用户名、显示名称、角色、注册时间、最近登录时间、账号状态和有效 Session 数量；
- 创建新账号，即使自主注册已经关闭；
- 修改用户的用户名和显示名称；
- 启用或停用账号；
- 将普通用户提升为超级管理员，或在安全条件满足时降级其他超级管理员；
- 为其他用户重置密码；
- 重置密码时立即注销该用户全部旧 Session。

为了保护学习数据，管理页当前不提供“硬删除用户”操作。离职、停用或不再使用的账号应优先使用“停用账号”，对应用户数据库和备份仍会保留。

## 学习运营大屏

`/admin/report` 是面向超级管理员的大屏报表，可全屏展示，并默认每 60 秒刷新一次。

主要指标包括：

- 注册用户数、启用用户数、已开始学习人数；
- 近 7 天活跃人数；
- 全员平均学习进度；
- Week 0～18 每周平均进度、开始人数和完成人数；
- 系统考试总次数与通过率；
- 代码实训总次数与通过率；
- 用户整体进度分布；
- 每个用户的总进度、完成课程数、当前周、考试表现、代码实训表现和最近活动时间。

点击大屏中的用户，可进入 `/admin/users/<id>/progress` 查看该用户 Week 0～18 的逐周进度和系统成绩。

### 报表隐私边界

管理员报表只读取每个独立用户数据库中的白名单统计表：

```text
lesson_progress
exam_attempts
code_attempts
```

不会读取或输出：

```text
thoughts
resources 的正文内容
code_attempts.source_code
password_hash
storage_key
用户数据库路径
```

也就是说，超级管理员能够管理“学习进度与完成情况”，但不会因此获得用户私人知识记录的浏览权限。

## 自主注册控制

超级管理员可以直接在“用户管理”中即时：

```text
开启自主注册
停止自主注册
```

该设置保存在全局 `accounts.db` 的 `system_settings` 中，修改后立即生效，**不需要重启 Python 或 Docker**。

关闭后：

- `/register` 立即返回 `403`；
- 已有用户仍可正常登录；
- 超级管理员仍可以从用户管理页手工创建账号。

环境变量：

```text
LLM_ALLOW_REGISTRATION=1
```

现在只作为**首次启动、尚未保存后台设置时的默认值**。一旦超级管理员在后台切换过注册策略，就以 `accounts.db` 中保存的设置为准。

## 用户自己修改密码

所有用户均可进入：

```text
/account
```

修改自己的用户名、显示名称和密码。修改密码需要输入当前密码；成功后该账号的全部 Session 会立即失效，并要求使用新密码重新登录。

## 数据隔离与管理边界

全局账号与设置：

```text
data/accounts.db
```

用户学习数据继续物理隔离：

```text
data/users/<storage-key>/learning.db
```

超级管理员跨用户读取只用于上述学习统计，不把多个用户的数据库合并，也不会修改用户的课程、考试或实训数据。

## 安全行为

- 密码使用带随机 Salt 的 PBKDF2-HMAC-SHA256 保存，不保存明文密码。
- Session Cookie 为 HttpOnly。
- 数据库只保存 Session Token 的 SHA-256 摘要。
- 管理员重置密码、停用账号都会撤销目标用户现有 Session。
- 普通用户不能调用超级管理员路由。
- 管理报表 JSON 不包含密码摘要、storage key、私人笔记或代码源文件。
- CI 同时验证 Python 权限测试和真实 Docker 中的大屏权限、跨用户隔离与注册开关。
